## 0. 结论速览（TL;DR）

| 决策点 | 结论 | PRD 承接 |
|---|---|---|
| 本地存储 | **Room 2.8.4 + KSP**（不用 kapt），schema 导出到 `app/schemas` | Q1 / FR-41 |
| 物品归属 | **`item.locationId` 单一归属（一物一处）**，`NOT NULL` + 外键 `ON DELETE RESTRICT` + 索引；同名物品是独立实体，**身份一律以 `id` 判定**（约束 A-6） | Q2 / [PRD 08 数据字段业务语义](../prd/08-数据字段业务语义.md) §7.3 / FR-10 |
| 搜索 | **Room 全量投影 → 内存归一化索引**（不用 FTS），数据量超阈值降级到 SQL `LIKE` | FR-19/20/21/22、NFR-05/06 |
| 拼音 | **houbb pinyin `com.github.houbb:pinyin:0.4.0`（Maven Central，Apache-2.0，离线）**，录入/更新时**预生成并持久化**全拼 + 首字母；**不需要 JitPack 仓库** | FR-20 / Q8 / [07-依赖包清单.md §6.7](07-依赖包清单.md) |
| DI | **Hilt 2.57.1（KSP）**，与 Room 共用同一 KSP 管道 | NFR-03 |
| 导航 | **Navigation Compose 2.9.6 + kotlinx.serialization 类型安全路由** | [07-依赖包清单.md §6.1/§6.2](07-依赖包清单.md) |
| 时间 API | **启用 core library desugaring（desugar_jdk_libs 2.1.5）+ `java.time`**，DB 内一律存 **Long epoch millis (UTC)** | minSdk 24 坑 / [PRD 08 数据字段业务语义](../prd/08-数据字段业务语义.md) §7.1 |
| 序列化 | **kotlinx-serialization-json 1.9.0**（同时服务导出与导航路由，共享插件） | FR-42/43 / Q5 |
| ID | **String UUID（应用侧生成）**，内置项用固定哨兵 UUID | FR-43 导入合并 |
| 状态存储 | **稳定字符串 code**（非 Int），向前兼容新增状态 | FR-25 / [PRD 06 必须正面处理的难点](../prd/06-必须正面处理的难点.md) §5.2 |

**任务总数 5 个**（T-01…T-05，含内部子步骤）：P0 闭环 = T-01～T-04，P1 增强 = T-05。详见 [11-任务列表.md](11-任务列表.md)。
