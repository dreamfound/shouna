### 6.4 `settings.gradle.kts` 草稿（**无需改动**）

> **决策：不新增任何外部仓库。** 拼音库改用 Maven Central 上的 `com.github.houbb:pinyin:0.4.0`（理由见 §6.7），因此**不再需要 JitPack**——`settings.gradle.kts` 保持现状即可：
>
> ```kotlin
> dependencyResolutionManagement {
>     repositories {
>         google()
>         mavenCentral()
>         // 不添加 jitpack.io（拼音依赖已改为 Maven Central 直取）
>     }
> }
> ```
>
> 预期收益：**少一个外部仓库 = 少一个构建失败点**（JitPack 按 git tag 现构建、可能限流/超时）。
