> 本文件回答：跨文件的命名 / 状态 / 时间 / ID / 测试等统一约定是什么。
> 依赖：03 关键架构判断 ｜ 被依赖：全部实现任务

> **路径基准**：工程根 = `shouna/`
> 源码根 = `app/src/main/java/com/dream/shouna/`（未加前缀的源码路径均以此为准）
> 单测根 = `app/src/test/java/com/dream/shouna/`
> 仪器测试根 = `app/src/androidTest/java/com/dream/shouna/`
> 资源根 = `app/src/main/res/`

## 7. 共享知识（跨文件约定）

1. **包结构与命名**
   - 根包 `com.dream.shouna`；分层：`data.local.{entity,dao,relation,converter}`、`data.repository`、`domain.{model,search,usecase}`、`ui.{screen,component,navigation,theme}`、`util`、`di`。
   - 实体类后缀 `Entity`；DAO 后缀 `Dao`；仓库接口无后缀、实现后缀 `Impl`；页面 `XxxScreen` + `XxxViewModel`；路由 `XxxRoute`。
   - 一个文件一个顶层 public 类（枚举/DTO 可例外放同文件）。

2. **UiState 约定**
   - 每个页面一个 `data class XxxUiState(...)`（不可变，全默认值），由 `MutableStateFlow` 驱动，对外 `StateFlow`。
   - 一次性事件用 `Channel`/`SharedFlow`（如 Toast/导航），**不进 UiState**。
   - 加载态用 `isLoading: Boolean` + `emptyReason: EmptyReason?`，不引入封装 `Result` 包装类到 UI。

3. **Result / 错误处理约定**
   - 仓库一次性命令返回 `domain` 层自定义结果（`ExportResult`/`ImportResult`/`DeleteResult`），或用 Kotlin `Result<T>`；**不把异常抛到 UI**。
   - ViewModel 负责 `runCatching` → 映射为 `errorMessage`/`isError` 字段；UI 只读状态。

4. **时间**
   - 统一类型：domain 层用 `kotlinx.datetime` 风格的 **`java.time.Instant`**（经 desugaring）；**DB 一律 `Long`（epoch millis, UTC）**；导出 JSON 用 **ISO-8601 UTC 字符串**（`Instant.toString()`）。
   - 显示时区：**本地时区**格式化（`DateTimeFormatter` + `ZoneId.systemDefault()`）；存储/比较永久 UTC。
   - 禁止在业务代码里 new `Calendar`/`Date`（除 desugaring 内部）。

5. **ID 生成**
   - 全部主键用 **`IdGenerator.newId()` = `UUID.randomUUID().toString()`**（应用生成，非 DB 自增）。
   - 内置项用**固定哨兵 UUID 常量**：`IdGenerator.UNSPECIFIED_LOCATION_ID`、`IdGenerator.TO_BE_PUT_BACK_LOCATION_ID`，以及 6–8 个内置分类 ID，便于识别与合并。

6. **字符串资源与硬编码**
   - 所有面向用户的文案放 `app/src/main/res/values/strings.xml`（便于本地化与可访问性）；**业务常量**（阈值枚举、状态 code、拼音分隔符、搜索权重、降级阈值）放 Kotlin `object`/`enum`。
   - 不在 Composable 里硬编码中文文案。

7. **Preview 约定**
   - 每个 `XxxScreen` 提供 `@Preview`：至少一个亮色、一个 `@Preview(uiMode = UI_MODE_NIGHT_YES)`；使用 `kapt`-free 的假 UiState；**Preview 不依赖 Hilt**（把 Screen 做成接收 `uiState` + 回调的无状态 Composable，`XxxRoute` 才取 ViewModel）。

8. **测试约定**
   - **单元测试**放 `app/src/test/java/com/dream/shouna/`（单测根）：纯逻辑（`SearchIndex`、`PinyinUtil`、`TextNormalizer`、Repository 用 Fake DAO），断言用 **Truth**（`assertThat`），协程用 `kotlinx-coroutines-test`（`runTest`）。
   - **仪器/DB 测试**放 `app/src/androidTest/java/com/dream/shouna/`（仪器测试根）：Room 用 `Room.inMemoryDatabaseBuilder`；迁移测试用导出的 schema。
   - 命名：`被测类`+`Test`；每条用例注释对应 FR/NFR 编号（可追溯）。

9. **事务与线程**
   - 所有 DB 写入走 `Dispatchers.IO`；跨表写入用 `database.withTransaction { }`。
   - Repository 是**唯一**事务边界；ViewModel 不直接持有 `ShounaDatabase`。
