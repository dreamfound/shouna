## 4. 调用流程（时序图）

### 4.1 连续录入 N 件物品（含检索键生成 + 事务写入）

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant S as QuickAddScreen
    participant VM as QuickAddViewModel
    participant R as ItemRepository
    participant PY as PinyinUtil
    participant NRM as TextNormalizer
    participant DAO as ItemDao / PlacementDao
    participant DB as ShounaDatabase
    participant LD as LocationDao

    U->>S: 选位置「纸箱-07」并输入「电风扇」+ 回车
    S->>VM: onSave()
    VM->>R: createItemQuick("电风扇", "纸箱-07", catId, 1)
    R->>NRM: normalize("电风扇")
    NRM-->>R: "电风扇"
    R->>PY: toFullPinyin / toInitials
    PY-->>R: "dianfengshan" / "dsf"
    R->>DB: withTransaction { }
    R->>DAO: insert(ItemEntity(id=UUID, normalized, pinyin, status=in_storage,<br/>createdAt=now, lastModifiedAt=now, lastConfirmedAt=null))
    R->>DAO: insert(PlacementEntity(itemId, locationId, isPrimary=1, quantity=null))
    R->>LD: touchRecent("纸箱-07", now)
    DB-->>R: 提交成功
    R-->>VM: newItemId
    VM-->>S: sessionCount++ ，inputName=""
    S-->>U: 输入框清空并保持焦点，显示「已连续录入 N 件」
    Note over S,U: 连续录入期间不弹任何位置/分类对话框（FR-10 M7）
```

### 4.2 全局搜索（含归一化、权重排序、过滤失效物品）

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant S as SearchScreen
    participant VM as SearchViewModel
    participant R as ItemRepository
    participant IDX as SearchIndex
    participant SC as SearchScorer
    participant NRM as TextNormalizer
    participant DAO as ItemDao

    U->>S: 输入「dsf」（或「dianfengshan」/「风扇」）
    S->>VM: onQueryChange("dsf")
    Note over VM: collectLatest + debounce(80ms)
    VM->>NRM: normalize("dsf")
    NRM-->>VM: "dsf"
    VM->>IDX: query("dsf", filters, includeInactive=false, limit=50)
    IDX->>IDX: 内存遍历 docs，逐字段匹配
    IDX->>SC: 计算权重（NAME_PREFIX 1000 > NAME_SUBSTRING 800 ><br/>ALIAS 600 > PINYIN_INITIALS 500 > PINYIN_FULL 400 ><br/>TAG 200 > LOCATION 150 > CATEGORY 100）
    SC-->>IDX: 排序（同分按 lastConfirmedAt desc, createdAt desc）
    IDX-->>VM: List<SearchHit>
    VM-->>S: UiState(results, highlightRanges)
    S-->>U: 实时展示「电风扇 · 储物间›货架A›纸箱-07 · 3个月前确认过」
    Note over IDX: 索引来源：ItemRepository.observeSearchDocs()<br/>仅在文档指纹变化时重建
    IDX-->>DAO: (初次/失效时) 拉取最新 SearchDoc 快照
    Note over IDX: includeInactive=false 时过滤 discarded/given_away/used_up
```

### 4.3 移动物品位置（含主位置切换 + 双时间刷新）

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant S as ItemDetailScreen
    participant VM as ItemDetailViewModel
    participant R as ItemRepository
    participant PD as PlacementDao
    participant ID as ItemDao
    participant DB as ShounaDatabase

    U->>S: 点「移动位置」→ 选新位置「衣柜·顶层」
    S->>VM: onMove("衣柜-顶层")
    VM->>R: moveItem(itemId, toLocationId="顶层", asPrimary=true)
    R->>DB: withTransaction { }
    R->>PD: 若目标处已存在 placement → 合并数量，否则 insert(PlacementEntity(isPrimary=1))
    R->>PD: clearPrimary(itemId)  // 全部置 0（原主位置自动降级）
    R->>PD: setPrimaryFlag(itemId, "顶层")  // 置 1
    Note over PD: 部分唯一索引 index_placement_primary 保证不可能出现两个主位置
    R->>ID: updateStatus? 否 —— 仅刷新 lastModifiedAt
    R->>ID: UPDATE item SET lastModifiedAt = now WHERE id = itemId
    Note over ID: lastConfirmedAt 不刷新（移动≠确认）
    DB-->>R: 提交成功
    R-->>VM: ok
    VM-->>S: 刷新位置路径 + 最后变动时间
    S-->>U: 归属更新，旧位置不再显示该物品
```

### 4.4 导出与导入备份

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant S as BackupScreen
    participant VM as BackupViewModel
    participant SAF as SAF(ActivityResult)
    participant BR as BackupRepository
    participant DB as ShounaDatabase
    participant J as kotlinx.serialization

    rect rgb(240,248,255)
    Note over U,BR: 导出（不申请存储权限）
    U->>S: 点「导出备份」
    S->>SAF: CreateDocument("application/json") → ACTION_CREATE_DOCUMENT
    SAF-->>S: uri（用户选定位置）
    S->>VM: onExport(uri)
    VM->>BR: export(uri)
    BR->>DB: 读取 categories/locations/items/placements/aliases/tags/itemTags
    DB-->>BR: 全量快照
    BR->>J: encodeToString(BackupBundle(schemaVersion, appVersion, exportedAt, ...))
    BR->>SAF: openOutputStream(uri).write(json)
    BR-->>VM: ExportResult.Success(字节数)
    VM-->>S: 提示「导出成功」
    end

    rect rgb(255,245,240)
    Note over U,BR: 导入（先校验后写库，失败回滚）
    U->>S: 点「导入恢复」并选文件
    S->>SAF: OpenDocument(["application/json"]) → ACTION_OPEN_DOCUMENT
    SAF-->>S: uri
    S->>VM: onImport(uri, strategy=MERGE)
    VM->>BR: import(uri, MERGE)
    BR->>J: decodeFromString(BackupBundle)
    J-->>BR: bundle（或抛异常→Failure）
    BR->>BR: 引用完整性校验（placement.itemId/locationId 必须存在；<br/>location.parentId 必须存在或空；schemaVersion 兼容）
    alt 校验失败
        BR-->>VM: ImportResult.Failure(reason)
        VM-->>S: 明确错误提示（本地数据未改动）
    else 校验通过
        BR->>DB: withTransaction { OVERWRITE: 清表后插入 / MERGE: 按 ID upsert }
        DB-->>BR: 提交
        BR-->>VM: ImportResult.Success(新增/覆盖条数)
        VM-->>S: 提示导入结果
    end
    end
```

### 4.5 启动加载与首次种子数据初始化

```mermaid
sequenceDiagram
    autonumber
    participant OS as Android
    participant APP as ShounaApplication
    participant MA as MainActivity
    participant NAV as ShounaNavHost
    participant DB as ShounaDatabase
    participant CB as SeedCallback
    participant CFG as ConfigDao

    OS->>APP: onCreate()
    APP->>APP: @HiltAndroidApp 初始化 Hilt 容器（编译期生成，~0ms）
    OS->>MA: onCreate()
    MA->>DB: 首次 getDatabase()（惰性，避免阻塞首帧）
    alt 首次安装（DB 文件不存在）
        DB->>DB: 创建表 + 索引（含部分唯一索引）
        DB->>CB: onCreate(db)
        CB->>DB: execSQL 插入 6–8 内置分类 + 待归位区 + 未指定位置（固定哨兵 UUID）
    end
    DB-->>MA: Database 就绪（放在 IO 线程，不阻塞首帧）
    MA->>NAV: setContent { ShounaTheme { ShounaNavHost() } }
    NAV->>CFG: observe("onboarding_done")
    alt 未完成引导
        NAV-->>OS: 展示 OnboardingRoute（可跳过）
    else 已完成引导
        NAV-->>OS: 展示 HomeRoute
    end
    Note over MA,DB: 冷启动 ≤1.5s 关键：DB/索引/拼音键均不在主线程同步构建
```
