# 测试须知

> 路径基准：工程根 `shouna/` ｜ 版本 **v1.0**（2026-10-09 立）

## 文档职责

本文件是**「跑测试之前必须知道什么」的唯一入口** —— 尤其：**哪些测试不许自行跑**。

它只回答「跑不跑、怎么跑、跑完要说什么」，**不复制测试清单**（那份在 `docs/code-map/05-改动须知.md` §2 的测试地图，本文件只指过去）。

## 阅读入口

- **何时读**：**跑任何测试之前必读**（AI 助手跑、人跑都算）；新增或修改测试文件之前必读。
- **读法**：§1 是硬规则（违反会花钱）；§2 是本项目跑测试的真相（含一条「默认跳过」在这台机器上**不成立**的陷阱）；§3 是四种合法跑法。
- **前置约束**：`AGENTS.md`（协作规则）；测试文件清单与例数见 `docs/code-map/05-改动须知.md` §2。
- **不适用**：只写测试用例、不运行它们时。

## 1. 硬规则：AI 能力测试必须先取得同意（2026-10-09 立）

| # | 规则 | 说明 |
|---|---|---|
| 1-1 | **未经用户明确同意，不得进行任何 AI 能力测试** | 「AI 能力测试」= 任何会**真的调用模型服务**的验证：真发 HTTPS 请求、真出网、消耗额度。 |
| 1-2 | 同一规则覆盖**生成类**（图片 / 视频 / 3D 等花额度的操作） | 与「真调模型」同性质，同样先问。 |
| 1-3 | **离线替身不算 AI 能力测试** | `RecordingAiHttp`（假传输）、`FakeDaos`（假 DAO）、纯 JVM 逻辑、Room 真库 SQL、迁移验证 —— 不触网，随时可跑。 |
| 1-4 | **同意只对当次有效** | 上一轮同意过 ≠ 本轮可以跑；每次运行前重新确认。 |
| 1-5 | **跑了真调必须主动声明** | 结论里写明「本次含 N 次真实调用」，不许混进「单测全绿」一笔带过。 |

| # | 事实 | 证据 / 真源 |
|---|---|---|
| 2-1 | 单测里**唯一**的出网点是 `data/remote/ai/AiLiveSmokeTest.kt`（3 例，真调 `api.deepseek.com`） | 该文件类注释；`code-map/05-改动须知.md` §2 |

## 3. 四种合法跑法

**（甲）默认：先问。** 要跑测试（尤其全量）先向用户申请；这是本文件存在的意义。

**（乙）离线白名单：排除冒烟，其余全跑。** Gradle 的 `--tests` **只支持白名单、不支持 `!` 取反**，所以只能逐个列出（PowerShell，反引号续行）：

```powershell
.\gradlew.bat :app:testDebugUnitTest --console=plain `
  --tests "com.dream.shouna.ExampleUnitTest" `
  --tests "com.dream.shouna.data.memory.*" `
  --tests "com.dream.shouna.data.remote.ai.AiPromptTest" `
  --tests "com.dream.shouna.data.remote.ai.DeepSeekAiClientTest" `
  --tests "com.dream.shouna.data.repository.*" `
  --tests "com.dream.shouna.domain.*" `
  --tests "com.dream.shouna.util.*"
```

期望 **221 例 / skipped=0**（224 − 3），结果里**不含** `AiLiveSmokeTest`。增删测试文件时同步这套白名单。

⚠️ **千万别图省事写成 `com.dream.shouna.data.remote.ai.*`** —— Gradle 官方口径：通配符 `*` **「对 `.` 包分隔符没有任何特殊理解，纯文本匹配」**（`*.SomeTestClass` 可匹配任意深度包名），所以那一条会把 `AiLiveSmokeTest` 一起扫进去、当场真调。改这套白名单后，先核对**这里没有 `data.remote.ai.*`、也没有任何 `*AiLiveSmoke*`**。

**（丙）经同意后真调**（只在用户点头之后）：

```powershell
.\gradlew.bat :app:testDebugUnitTest --tests '*AiLiveSmokeTest*' -i
```

期望 3 例通过、约 1–2 s/例；跑完按 §1-5 声明。

**（丁）只验能不能编过**（不跑测试、不触网）：`.\gradlew.bat :app:compileDebugKotlin`。

## 4. 维护口径

- 新增**任何会出网**的测试，**必须**同时更新本文件 §2（否则下一个人会以为单测全离线）。
- **不采用代码门禁**（不加「必须显式开关才真调」这类逻辑）—— 用户 2026-10-09 明确要求：这条规则靠**「一定要读的文档」**约束，不靠代码兜底。**因此读到本文件就是唯一的防线。**
- 规则有变（用户放宽或收紧）→ 改 §1 并加日期，**不升版本号**。
