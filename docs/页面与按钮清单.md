> 口径：**只写代码里已经有的**。每一项一句话，说清「点了会发生什么」。
> 页面代码位置见 [`code-map/01-界面层.md`](code-map/01-界面层.md)；本文不写分层、不写实现细节。
> 依据：2026-10-08 读 `ui/` 全量源码（2026-10-09 随「语音 AI 录入」与「拍照 AI 录入」各自独立成页、并在同日把两页结果形态统一为**逐条确认弹窗**时更新；**2026-10-10 随接入内置离线识别引擎时更新 —— 同日试过的「语音 AI 录入页录音直送」已回退**）；页面 = `ui/navigation/ShounaRoute.kt` 的 **11 个**路由，与路由一对一。

## 1. 首页（P-HOME）

| 控件 | 一句话 |
|---|---|
| 搜索框（只读） | 点击进入搜索页，并自动聚焦到搜索页的输入框。 |
| 「＋ 记一件」 | 进入连续录入页，位置条按「最近使用」预选。 |
| 「🎤 语音AI记」 | **进入语音 AI 录入页**（`VoiceAiIntake`）—— 话筒、逐条确认弹窗都在那一页里完成。**仅 AI 总开关开启时出现**。 |
| 「📷 拍照AI记」 | **进入拍照 AI 录入页**（`PhotoAiIntake`）—— 位置、照片、识别与逐条确认弹窗都在那一页里完成。**仅 AI 总开关开启时出现**。 |
| 「更多」/「收起」 | 展开或收起折叠区（折叠区本身不是页面，只是本页的一块显隐区域）。 |
| 「位置浏览」（折叠区内） | 进入位置浏览页的根级（全部位置）。 |
| 「归纳统计」（折叠区内） | 进入统计页的卡片态。 |
| 「设置」（折叠区内） | 进入设置页。 |

首页**不再有 AI 状态区与确认卡**（2026-10-09 两条 AI 通道各自独立成页后，整块移出本页）：两个 AI 入口都只做导航，AI 的识别进度、失败提示、逐条确认与落库汇总全部在各自那一页里。

空态时显示文案「还没有记录，点「＋ 记一件」开始」，不是按钮。

## 2. 语音 AI 录入页（P-VOICE-AI）

| 控件 | 一句话 |
|---|---|
| 页内话筒 | **长按说话、松手出字**（没有「识别」按钮）—— 不需要先选位置，位置由你**说的那段话**决定。识别在**本机**完成、音频不出设备（走 `VoiceCapturePad`）。 |
| ⚠️ 页内临时件（定案后移除） | 两处：① 话筒下方一个测试输入框 +「发送」（走同一条链路、直接送**文字**，方便不下嘴也能试）；②「识别引擎都起不来」时的一段诊断快照（在 `VoiceCapturePad` 里）。 |
| 页内状态行 | 识别中一行「AI 识别中…」；失败一行提示（「没配密钥」「没识别出」等，直接说清下一步做什么）；AI 总开关在别处被关掉时给一行红字。 |
| 确认弹窗（标题「确认第 i / N 件」） | 识别出的每件**各弹一次**；一句话里有几件就弹几次。 |
| 弹窗内「名称」输入框 | 改这一件的名称；名称空白时「确认」禁用。 |
| 弹窗内「位置：…」一行 | **可以点、可以改** —— 位置是 AI 从你那句话里猜的。猜到的层在库里不存在时会**就近降级**（例如「客厅的抽屉」而「抽屉」不存在 ⇒ 记到「客厅」，行上会标出「已就近」）；一个祖先都没对上时，这一行的「确认」置灰，**先补一个位置**才能记下。 |
| 点位置行 → **位置选择态** | 同一棵树就地铺开（不开第二个窗口）。**这一屏换一套按钮**：底部只留「取消」（退回表单），「确认 / 放弃」与右上角「关闭」在此屏**都隐去** —— 免得把「离开这一屏」误当成「丢掉这一件 / 丢掉整轮」。按返回键 / 点窗外与「取消」同义；点树行即选中并自动回表单。 |
| 弹窗内「分类」chips | 改这一件的分类，再次点击已选 chip 取消选中；不选也能确认。 |
| 弹窗内「备注」输入框 | 改这一件的备注。 |
| 弹窗「确认」 | **立刻弹下一件**（不为写库等待）；这一件的写库在**后台串行队列**里按点击顺序执行。 |
| 弹窗「放弃」 | 跳过这一件，继续弹下一件；不落库，**也不算「没记下」**。 |
| 弹窗「关闭」（右上角） | **放弃本次录入**：剩下没处理的一并丢掉（**已确认的留在库里**）。点弹窗外、按系统返回键与它同义。**位置选择态里本按钮不出现**（那一屏按返回键 / 点窗外 = 退回表单，不丢件）。 |
| 落库汇总 | 队列走完 / 关闭之后，留一行「已记下 N 件」；有没记下的，另起一行用错误色说明件数。**留在本页**，可以接着说下一句。 |

语音通道**不新建位置**：模型说出的位置里，只有已经存在的层会被采用，更深的不存在的层会被丢掉（并在弹窗上明说「已就近」）—— 需要新增位置请到位置浏览页去建。

## 3. 拍照 AI 录入页（P-PHOTO-AI）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 回上一页；那一张还没被落库的临时照片会同时删掉（已落库的不受影响），**但删之前先判引用** —— 还有写库在途（`pendingCommits > 0`）或库里已有记录指着它时都不删。系统返回键与它同一行为。 |
| 位置条 | 打开位置选择弹层（内可「＋ 新建位置」）；进页按「最近使用」预选；未选时显示红色「选择位置（必填）」。 |
| 「📷 拍照」 | 调系统相机拍一张照，作为本次**识别**的输入。 |
| 「🖼 从相册」 | 打开系统照片选择器选一张图作为识别输入。 |
| 「移除照片」 | 清掉当前待识别的照片（有照片时才出现）。 |
| 「识别」 | 把这张照片发给 AI 拆成多件；**未选位置或没拍照时禁用**，并在按钮下方给出红字原因。 |
| 确认弹窗（标题「确认第 i / N 件」） | 识别出的每件**各弹一次**（一次只呈现一件），不再在页面上铺一张卡。 |
| 弹窗内「名称」输入框 | 改这一件的名称；名称空白时「确认」禁用。 |
| 弹窗内「位置：…」一行 | **只读** —— 位置在识别前就定了（要换位置只能「关闭」本次、回页面重选再识别）。 |
| 弹窗内「分类」chips | 改这一件的分类，再次点击已选 chip 取消选中；不选也能确认。 |
| 弹窗内「备注」输入框 | 改这一件的备注。 |
| 弹窗「确认」 | **立刻弹下一件**（不为写库等待）；这一件的写库在**后台串行队列**里按点击顺序一件件执行，所以点得再快也不会重复记同一件。 |
| 弹窗「放弃」 | 跳过这一件，继续弹下一件；这一件不落库，**也不算「没记下」**。 |
| 弹窗「关闭」（右上角） | **放弃本次录入**：剩下没处理的一并丢掉（**已确认的留在库里**）。点弹窗外、按系统返回键与它同义。 |
| 落库汇总 | 队列走完 / 关闭之后，留一行「已记下 N 件」；有没记下的，另起一行用错误色说明件数。写库在后台，汇总可能在弹窗收掉之后才现身。**留在本页**，可接着拍下一张。 |

一张照片可以记多件：识别出的每一件都落到**同一个**位置（位置在这一页里先定），并共用这一张照片（`photo_path` 只存文件名，不是复制 N 份）——**默认就带着这张照片**，用户在详情页或编辑页可以删掉它；因为多条记录共用同一个文件，删除时**只有最后一个引用者才真删文件**，不会把其他记录的照片弄成破图（另外，刚点完确认、写库还在后台跑的那几件，其引用**还没进库**，此时**一律不删**）。

照片行上方的通用标签「照片（可选）」来自 FR-16 的 `PhotoInputRow`（录入页语义）—— **在本页照片是必填**（没照片则「识别」不可点）。

## 4. 连续录入页（P-ADD）

| 控件 | 一句话 |
|---|---|
| 位置条 | 打开位置选择弹层；未选位置时显示红色「选择位置（必填）」。 |
| 物品名称输入框 | 输入名称（进页自动聚焦）；键盘「完成」键只收起键盘，不代替保存。 |
| 名称框尾部 🎤 | 打开语音弹窗，识别结果写入**名称**。 |
| 名称框尾部 AI 按钮 | 交给 AI 解析（只 AI 总开关开启时出现）：填了名称走文字、挂了照片走照片；单件回填本表单、多件写进库（页内确认卡）。 |
| 「查看」（重名提示行） | 跳到最后保存的那件、与它同名或相近的物品详情页；提示行在保存后且命中相似时才出现。 |
| 分类 chips | 点选分类，再次点击已选 chip 取消选中；不选也能保存。 |
| 「📷 拍照」 | 调系统相机拍照并作为该物品的照片。 |
| 「🖼 从相册」 | 打开系统照片选择器选一张图作为物品照片。 |
| 「移除照片」 | 清掉当前待保存的照片（有照片时才出现）。 |
| 「添加备注」/「收起备注」 | 展开或折叠备注输入框（备注可跳过）。 |
| 备注框尾部 🎤 | 打开语音弹窗，识别结果写入**备注**。 |
| 「保存并继续」 | 保存当前这件、清空名称、保留位置与焦点，接着记下一件；位置未选或名称为空时禁用。 |

「请先选择或新建一个位置」（位置未选时）与「本次已记录 N 件」都是文案，不是按钮。

## 5. 位置浏览页（P-BROWSE）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 回上一页。 |
| 子位置行 | 点击下钻到该子位置那一层。 |
| 物品行 | 点击进入该物品的详情页（本页行不支持长按复制，复制只在搜索页与详情页提供）。 |
| 「＋ 往这里记一件」（仅非根级） | 带着当前这一层进入连续录入页，位置条预选该层。 |
| 「＋ 子位置」 | 弹输入框，在当前层之下新建一个子位置。 |
| 「重命名」（仅非根级） | 弹输入框，改当前这一层的名字。 |
| 「删除」（仅非根级） | 弹二次确认，二选一：把该位置及子位置删除、其下物品「标记不在了」；或把这些物品迁移到别的位置。 |
| 「移动到…」（仅非根级） | 弹目标选择，把当前这一层挂到别的父级下（含单独一行「移到最外层（根级）」）。 |
| 「合并到…」（仅非根级） | 弹目标选择，把当前这一层的物品并进所选位置。 |
| 「标记临时」/「取消临时」（仅非根级） | 切换当前这一层的临时位置标记。 |
| 「全部确认」（仅非根级） | 弹确认框（写明含子层共几件），为当前层及所有子层下的物品各记一次「还在」。 |

弹层内的按钮：新建子位置 / 重命名对话框各给「确定」「取消」（名称为空时「确定」禁用）；删除确认给「标记不在了并删除」「迁移物品到…」「取消」；迁移目标弹层只列既有位置（无新建入口）；移动 / 合并目标弹层给「取消」；全部确认给「确认 N 件」「取消」。

## 6. 搜索页（P-SEARCH）

| 控件 | 一句话 |
|---|---|
| 搜索框 | 输入即搜（带防抖，不需按回车）；键盘搜索键只收起键盘。 |

## 7. 物品详情页（P-ITEM-DETAIL）

| 控件 | 一句话 |
|---|---|
| 「恢复为「在存放中」」 | 把已标记「不在了」的物品恢复为在存放中（仅该状态下出现，恢复本身也算一次确认）。 |
| 「✓ 还在」 | 给这件物品记一次确认，刷新「最后确认」时间。 |
| 「✕ 不在了」 | 把这件物品标记为「不在了」。 |
| 「移除照片」 | 删掉这件物品的照片（仅在有照片时出现，只此一处给删除入口）；**如果这张照片还有别的记录在用，只解除这一条的绑定、文件保留**（拍照 AI 录入一次可记多件，它们共用同一个文件）。 |
| 「✏ 编辑」 | 进入物品编辑页。 |
| 「⋯更多」/「收起」 | 展开或收起折叠区。 |
| 「标记待归位」/「归位」（折叠区内） | 切换这件物品的待归位状态。 |
| 「移动到…」（折叠区内） | 弹位置选择，把物品换到另一个位置。 |
| 「编辑分类 / 别名 / 数量 / 备注」（折叠区内） | 进入物品编辑页（与「✏ 编辑」是同一个去处）。 |

位置面包屑长按可复制路径（非按钮）。

## 8. 物品编辑页（P-ITEM-EDIT）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 直接回上一页，不保存改动。 |
| 名称输入框 | 改名称；为空时标红并禁用保存。 |
| 「📷 拍照」 | 调系统相机拍一张新照片替换原有照片（**不在此时**删旧文件，留到保存成功后才删；且仅当没有别的记录还在用那个旧文件时）。 |
| 「🖼 从相册」 | 从系统照片选择器选一张图替换原有照片（同样延迟删除，同样先判引用）。 |
| 「移除照片」 | 标记为不要照片，保存后才真正清掉；旧文件若还有别的记录在用，则只解除这一条的绑定、文件保留。 |
| 「更换」（位置行右侧） | 弹位置选择，从**既有**位置里给物品换一个去处（不提供在此新建位置）。 |
| 分类 chips | 改分类，再次点击取消选中。 |
| 别名「添加」 | 把输入框里的草稿加为别名（已达上限或草稿为空时禁用）。 |
| 别名 chip 上的「✕」 | 直接删掉这个别名，不再二次确认。 |
| 数量输入框 | 改数量（数字键盘）；非不小于 1 的整数时标红并禁用保存。 |
| 备注输入框 | 改备注。 |
| 「保存」 | 只提交变化过的字段、成功后回上一页；名称或数量非法时禁用。 |

## 9. 归纳统计页（P-STATS）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 卡片态下回上一页；明细态下先退回卡片态。 |
| 「物品总数」卡片（带「查看全部物品 ›」） | 下钻到「全部物品」明细清单。 |
| 「位置总数」卡片 | 不可点，只展示数字。 |

## 12. 跨页面复用的弹层与交互（不是独立页面）

| 组件 | 出现位置 | 一句话 |
|---|---|---|
| 位置选择弹层 | 录入页、详情页「移动到…」、编辑页「更换」、浏览页迁移 / 移动 / 合并、统计页「归位到…」、**拍照 AI 录入页** | 标题「选择位置」；顶部「最近 · xxx」chip 一键落位；「＋ 新建位置」输入名称后点「创建」；点树行即选中，箭头 ▾/▸ 只切展开不触发选中；调目标的场景关掉新建入口。 |
| 逐条确认弹窗内的**位置选择态** | **仅语音 AI 录入页**（点弹窗里那行位置进入） | **不是弹层**：同一棵位置树直接铺在弹窗的正文槽里，标题「为「xxx」选择位置」；**没有「最近」chip、没有「＋ 新建位置」**（语音通道口径 = 落到已存在的祖先、不新建）；点树行即选中并**自动回表单**，故无「确定」。**该屏不共用表单态按钮**：底部只留一个「取消」（退回表单），「确认 / 放弃」与右上角「关闭」在此屏都隐去 —— 免得把「离开这一屏」误当成「丢掉这一件 / 丢掉整轮」；返回键 / 点窗外与「取消」同义。 |
| 移动 / 合并目标弹层 | 浏览页 | 列出可选位置（当前层自身与子树不在其中），点一行即选定，「取消」返回。 |
| 语音输入弹窗 | 录入页名称框与备注框的 🎤（**语音 AI 录入页不套弹窗** —— 页内直接摆同一个 `VoiceCapturePad` 组件） | 无权限时给「授予录音权限」；有权限时长按话筒说话、抬手结束，识别结果回填；「关闭」退出，识别失败留在弹窗内可重试。 |
| 逐条确认弹窗 | 拍照 AI 录入页、语音 AI 录入页 | 一件一弹（标题「确认第 i / N 件」）。可改名称 / 分类 / 备注；位置：**语音页可改**（点位置行即铺开位置树）、**拍照页只读**。表单态三个出口「确认 / 放弃 / 关闭」；（仅语音页）位置选择态**换一套按钮**：只留「取消」、其余隐去。「确认」立刻弹下一件、写库在后台串行队列里跑。 |
| 照片输入行 | 录入页、编辑页、**拍照 AI 录入页** | 三个动作：「📷 拍照」「🖼 从相册」「移除照片」（无照片时不给移除）。 |
| 点空白收键盘 | 所有页面（挂在唯一 NavHost 上） | 点击没有任何控件接管的空白区即收起键盘，点按钮与输入框不受影响。 |

## 13. 边界 · 现在**没有**的入口（避免按文档去找）

- **没有「删除物品」**：详情页与列表都没有该入口（软删除 + 回收站是 P2 的 FR-49，尚未实现）。
- **没有「批量改分类」入口**：录入页底部的「本次已记录 N 件」目前只是计数文案（P2 的 FR-15 尚未实现）。
- **拍照 AI 录入页的确认弹窗里不能改「位置」**：位置只读（识别前已定）。名称 / 分类 / 备注可改 —— 原 `V2-FR-11` 里「可逐行改分类」的子项已随逐条弹窗实现（2026-10-09）。
- **语音 AI 录入页的确认弹窗里「能」改位置**（与拍照页相反）：位置是 AI 从那句话里猜的，猜错 / 就近降级 / 压根没提，都能就地补或改；**补上位置前「确认」置灰**。
- **没有「显示完整功能」开关**：设置页只有阈值、分类管理、AI 录入、隐私说明、关于**五节**。
- **没有导出 / 导入 / 备份入口**：该能力 2026-09-29 已永久废弃。
- **位置浏览页的物品行不能长按复制路径**，复制只在搜索页结果行与详情页 / 浏览页面包屑上提供。
- **统计页下钻不新增路由**：卡片态与明细态是同一页的两个状态，返回键行为因此是「先回卡片态」。
