# 实现清单 · 页面与按钮

> 口径：**只写代码里已经有的**。每一项一句话，说清「点了会发生什么」。
> 页面代码位置见 [`code-map/01-界面层.md`](code-map/01-界面层.md)；本文不写分层、不写实现细节。
> 依据：2026-10-08 读 `ui/` 全量源码；页面 = `ui/navigation/ShounaRoute.kt` 的 9 个路由，与路由一对一。

## 0. 页面总表（9 页）

| 页面 | 路由 | 一句话 |
|---|---|---|
| 首页 | `Home` | 入口页：一个只读搜索框 + 一个「记一件」主按钮 + 两个 AI 入口（「说一句」语音 / 「拍照AI记」，均仅 AI 开启时出现）+ 一个折叠的「更多」区。 |
| 连续录入页 | `QuickAdd(locationId)` | 一件接一件记东西，位置必填、保存后焦点与位置都留着。 |
| 位置浏览页 | `LocationBrowse(locationId)` | 一次只看一层位置：上面面包屑、中间子位置与该层物品、底部管理与录入动作。 |
| 搜索页 | `Search(initialQuery)` | 输入即搜，没输入时给最近搜索词，有输入时给三维筛选 + 结果列表。 |
| 物品详情页 | `ItemDetail(itemId)` | 一件物品「在哪、还在不在」，次要字段与额外动作收在「⋯更多」折叠区里。 |
| 物品编辑页 | `ItemEdit(itemId)` | 改一件物品的七项字段（名称 / 照片 / 位置 / 分类 / 别名 / 数量 / 备注）。 |
| 归纳统计页 | `Stats` | 卡片态看总览与两个清单入口，明细态看具体清单，两态在同一页内切换。 |
| 设置页 | `Settings` | 调超期提醒阈值、进分类管理、配 AI 录入（总开关 / API Key / 本周期用量）、看隐私说明与关于。 |
| 分类管理页 | `CategoryManage` | 列出全部分类，可新建、改名，自定义分类可删除。 |

## 1. 首页（P-HOME）

| 控件 | 一句话 |
|---|---|
| 搜索框（只读） | 点击进入搜索页，并自动聚焦到搜索页的输入框。 |
| 「＋ 记一件」 | 进入连续录入页，位置条按「最近使用」预选。 |
| 「🎤 说一句」 | 打开语音弹窗（长按说话、松手出字）；识别结果**不落到输入框**，而是直接交给 AI；解析出多行草稿后在**本页**出现确认卡。**仅 AI 总开关开启时出现**。 |
| 「📷 拍照AI记」 | 在首页**页内展开**一块面板（**不是弹窗**）：**先**选位置（必填）→ **再**拍/选一张照片 → **最后**点「识别」；识别出多行草稿后同样在**本页**出现确认卡，点「收起」关掉面板。位置未选时「识别」不可点。**仅 AI 总开关开启时出现**。 |
| 「更多」/「收起」 | 展开或收起折叠区（折叠区本身不是页面，只是本页的一块显隐区域）。 |
| 「位置浏览」（折叠区内） | 进入位置浏览页的根级（全部位置）。 |
| 「归纳统计」（折叠区内） | 进入统计页的卡片态。 |
| 「设置」（折叠区内） | 进入设置页。 |

「🎤 说一句」与「📷 拍照AI记」下面都可能出现 AI 状态区（同一时刻只有一种）：一行「AI 识别中…」/ 一行失败提示 / 一张逐行勾选卡（勾选框 + 名称 + 位置 · 分类 · 备注；位置树里没有的层标「（待新建）」，连位置线索都没有的行标「缺位置，不会被记录」）配「忽略」「记下 / 全部记下」。**首页没有主表单可回填，所以 1 件与多件都是直接落库**。落库后留一行「已记下 N 件」；有没记下的，另起一行用错误色说明件数。

空态时显示文案「还没有记录，点「＋ 记一件」开始」，不是按钮。

## 2. 连续录入页（P-ADD）

| 控件 | 一句话 |
|---|---|
| 位置条 | 打开位置选择弹层；未选位置时显示红色「选择位置（必填）」。 |
| 物品名称输入框 | 输入名称（进页自动聚焦）；键盘「完成」键只收起键盘，不代替保存。 |
| 名称框尾部 🎤 | 打开语音弹窗，识别结果写入**名称**。 |
| 「查看」（重名提示行） | 跳到最后保存的那件、与它同名或相近的物品详情页；提示行在保存后且命中相似时才出现。 |
| 分类 chips | 点选分类，再次点击已选 chip 取消选中；不选也能保存。 |
| 「📷 拍照」 | 调系统相机拍照并作为该物品的照片。 |
| 「🖼 从相册」 | 打开系统照片选择器选一张图作为物品照片。 |
| 「移除照片」 | 清掉当前待保存的照片（有照片时才出现）。 |
| 「添加备注」/「收起备注」 | 展开或折叠备注输入框（备注可跳过）。 |
| 备注框尾部 🎤 | 打开语音弹窗，识别结果写入**备注**。 |
| 「保存并继续」 | 保存当前这件、清空名称、保留位置与焦点，接着记下一件；位置未选或名称为空时禁用。 |

「请先选择或新建一个位置」（位置未选时）与「本次已记录 N 件」都是文案，不是按钮。

## 3. 位置浏览页（P-BROWSE）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 回上一页。 |
| 子位置行 | 点击下钻到该子位置那一层。 |
| 物品行 | 点击进入该物品的详情页（本页行不支持长按复制，复制只在搜索页与详情页提供）。 |
| 「＋ 往这里记一件」（仅非根级） | 带着当前这一层进入连续录入页，位置条预选该层。 |
| 「＋ 子位置」 | 弹输入框，在当前层之下新建一个子位置。 |
| 「重命名」（仅非根级） | 弹输入框，改当前这一层的名字。 |
| 「删除」（仅非根级） | 弹二次确认，二选一：把该位置及子位置删除、其下物品「标记不在了」；或把这些物品迁移到别的位置。 |
| 「移动到…」（仅非根级） | 弹目标选择，把当前这一层挂到别的父级下（含单独一行「移到最外层（根级）」）。 |
| 「合并到…」（仅非根级） | 弹目标选择，把当前这一层的物品并进所选位置。 |
| 「标记临时」/「取消临时」（仅非根级） | 切换当前这一层的临时位置标记。 |
| 「全部确认」（仅非根级） | 弹确认框（写明含子层共几件），为当前层及所有子层下的物品各记一次「还在」。 |

弹层内的按钮：新建子位置 / 重命名对话框各给「确定」「取消」（名称为空时「确定」禁用）；删除确认给「标记不在了并删除」「迁移物品到…」「取消」；迁移目标弹层只列既有位置（无新建入口）；移动 / 合并目标弹层给「取消」；全部确认给「确认 N 件」「取消」。

## 4. 搜索页（P-SEARCH）

| 控件 | 一句话 |
|---|---|
| 搜索框 | 输入即搜（带防抖，不需按回车）；键盘搜索键只收起键盘。 |
| 「返回」 | 回上一页。 |
| 最近搜索词 chip（空态） | 把该词回填进输入框并立刻检索（没有历史记录时整块不出现）。 |
| 结果行 | 点击进入该物品详情页。 |
| 结果行副标题（长按） | 复制该物品的完整位置路径到剪贴板并吐司提示。 |
| 分类 / 位置 / 状态 筛选 chip | 点选收窄结果，再次点击已选 chip 取消该维度；三个维度可叠加。 |
| 「清空筛选」 | 一次清掉三个维度（仅在已有筛选时出现）。 |

## 5. 物品详情页（P-ITEM-DETAIL）

| 控件 | 一句话 |
|---|---|
| 「恢复为「在存放中」」 | 把已标记「不在了」的物品恢复为在存放中（仅该状态下出现，恢复本身也算一次确认）。 |
| 「✓ 还在」 | 给这件物品记一次确认，刷新「最后确认」时间。 |
| 「✕ 不在了」 | 把这件物品标记为「不在了」。 |
| 「移除照片」 | 删掉这件物品的照片（仅在有照片时出现，只此一处给删除入口）。 |
| 「✏ 编辑」 | 进入物品编辑页。 |
| 「⋯更多」/「收起」 | 展开或收起折叠区。 |
| 「标记待归位」/「归位」（折叠区内） | 切换这件物品的待归位状态。 |
| 「移动到…」（折叠区内） | 弹位置选择，把物品换到另一个位置。 |
| 「编辑分类 / 别名 / 数量 / 备注」（折叠区内） | 进入物品编辑页（与「✏ 编辑」是同一个去处）。 |

位置面包屑长按可复制路径（非按钮）。

## 6. 物品编辑页（P-ITEM-EDIT）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 直接回上一页，不保存改动。 |
| 名称输入框 | 改名称；为空时标红并禁用保存。 |
| 「📷 拍照」 | 调系统相机拍一张新照片替换原有照片（**不在此时**删旧文件，留到保存成功后才删）。 |
| 「🖼 从相册」 | 从系统照片选择器选一张图替换原有照片（同样延迟删除）。 |
| 「移除照片」 | 标记为不要照片，保存后才真正清掉。 |
| 「更换」（位置行右侧） | 弹位置选择，从**既有**位置里给物品换一个去处（不提供在此新建位置）。 |
| 分类 chips | 改分类，再次点击取消选中。 |
| 别名「添加」 | 把输入框里的草稿加为别名（已达上限或草稿为空时禁用）。 |
| 别名 chip 上的「✕」 | 直接删掉这个别名，不再二次确认。 |
| 数量输入框 | 改数量（数字键盘）；非不小于 1 的整数时标红并禁用保存。 |
| 备注输入框 | 改备注。 |
| 「保存」 | 只提交变化过的字段、成功后回上一页；名称或数量非法时禁用。 |

## 7. 归纳统计页（P-STATS）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 卡片态下回上一页；明细态下先退回卡片态。 |
| 「物品总数」卡片（带「查看全部物品 ›」） | 下钻到「全部物品」明细清单。 |
| 「位置总数」卡片 | 不可点，只展示数字。 |
| 「超期未确认」入口行 | 进入超期未确认清单（行上直接显示条数）。 |
| 「待归位」入口行 | 进入待归位清单（标记待归位、或放在临时位置上的物品，两者去重）。 |
| 明细行 | 点击进入该物品详情页（三种清单都一样）。 |
| 「确认还在」（超期清单行内） | 给该物品记一次确认。 |
| 「归位到…」（待归位清单行内） | 弹位置选择，把这件物品落到所选位置。 |
| 分类 / 位置 / 状态 筛选 chip +「清空筛选」 | 仅「全部物品」清单有，口径与搜索页三维筛选一致。 |

系统返回键在明细态下第一次按下等于「回卡片态」，不退出页面。

## 8. 设置页（P-SETTINGS）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 回上一页。 |
| 阈值 chip（3 / 6 / 12 个月） | 改超期提醒阈值，写入即刻生效，统计页 C-4 清单随之变化。 |
| 「分类管理」 | 进入分类管理页。 |
| AI 录入开关 | 总开关（默认关）；开启后录入页与首页才出现 AI 入口，关着时**连已生成的确认卡一起收掉**。 |
| API Key 输入框 + 「保存」 | 粘贴自己的 API Key（`PasswordVisualTransformation`，**只写入不回显**）；下方显示「已配置 / 未配置」；**关闭总开关不删密钥**。 |
| 「本周期用量」文案 | 只读显示本周期 AI 调用次数（成功才计数）。 |

「隐私说明」（数据仅本机、不可迁移、卸载即永久丢失）与「关于」（收纳助手 · 完全离线运行）是固定文案，无按钮。

## 9. 分类管理页（P-CATEGORY-MANAGE）

| 控件 | 一句话 |
|---|---|
| 「返回」 | 回上一页。 |
| 「＋ 新建」 | 弹输入框新建一个自定义分类。 |
| 「改名」（每行都有） | 弹输入框改该分类名称，内置分类也能改。 |
| 「删除」（仅自定义分类） | 二次确认后删除该分类，其下物品回落为「未分类」。 |
| 对话框「确定」/「取消」 | 提交或放弃新建 / 改名；名称空白时「确定」禁用。 |

内置分类只显示「内置」标签、不给删除入口。

## 10. 跨页面复用的弹层与交互（不是独立页面）

| 组件 | 出现位置 | 一句话 |
|---|---|---|
| 位置选择弹层 | 录入页、详情页「移动到…」、编辑页「更换」、浏览页迁移 / 移动 / 合并、统计页「归位到…」 | 标题「选择位置」；顶部「最近 · xxx」chip 一键落位；「＋ 新建位置」输入名称后点「创建」；点树行即选中，箭头 ▾/▸ 只切展开不触发选中；调目标的场景关掉新建入口。 |
| 移动 / 合并目标弹层 | 浏览页 | 列出可选位置（当前层自身与子树不在其中），点一行即选定，「取消」返回。 |
| 语音输入弹窗 | 录入页名称框与备注框的 🎤 | 无权限时给「授予录音权限」；有权限时长按话筒说话、抬手结束，识别结果回填；「关闭」退出，识别失败留在弹窗内可重试。 |
| 照片输入行 | 录入页、编辑页 | 三个动作：「📷 拍照」「🖼 从相册」「移除照片」（无照片时不给移除）。 |
| 点空白收键盘 | 所有页面（挂在唯一 NavHost 上） | 点击没有任何控件接管的空白区即收起键盘，点按钮与输入框不受影响。 |

## 11. 边界 · 现在**没有**的入口（避免按文档去找）

- **没有「删除物品」**：详情页与列表都没有该入口（软删除 + 回收站是 P2 的 FR-49，尚未实现）。
- **没有「批量改分类」入口**：录入页底部的「本次已记录 N 件」目前只是计数文案（P2 的 FR-15 尚未实现）。
- **没有「显示完整功能」开关**：设置页只有阈值、分类管理、AI 录入、隐私说明、关于**五节**。
- **没有导出 / 导入 / 备份入口**：该能力 2026-09-29 已永久废弃。
- **位置浏览页的物品行不能长按复制路径**，复制只在搜索页结果行与详情页 / 浏览页面包屑上提供。
- **统计页下钻不新增路由**：卡片态与明细态是同一页的两个状态，返回键行为因此是「先回卡片态」。
