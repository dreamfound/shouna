# 收纳助手（Shouna）产品需求文档 PRD

> 版本：**v1.5**（永久移除暗色模式与字号跟随） ｜ 语言：中文 ｜ 责任人：许清楚（产品经理） ｜ 交付总监：齐活林
> 类型：简单 PRD（单期交付，无竞品分析）。本文档只做**需求与业务语义定义**，不含代码、不定义表结构。
> **一句话结论**：做一个**纯离线的 Android 家庭物品收纳台账**——用最低的录入成本记住「这件东西有没有、放在哪个盒子哪一格」，需要时一次搜到。**默认只暴露「记一件 / 找一件」两件事，其余能力收在深层**，不把学习成本压给只想简单记录的用户。 本期（V1）只做离线台账、**不含任何 AI 能力**；AI 接入属 V2（规划与预留），见 [shouna/docs/prd/14-分期与V2-AI规划.md](shouna/docs/prd/14-分期与V2-AI规划.md)。
