# 实现地图 · 总入口

> 版本：**v1.0**（2026-09-29 立） ｜ 路径基准：工程根 `shouna/` ｜ 本目录 = `shouna/docs/code-map/`

## 文档职责

本文件是「实现地图」这一套的**唯一入口**：怎么用、分几层、目录怎么分、其余 5 份各管什么，以及
**「任务 → 文档章节 → 实现文件」的定位索引**。
逐文件职责在 `01`~`03`，端到端链路在 `04`，踩坑口径与测试在 `05` —— 本文件不重复这些内容。

本套只回答「代码现在在哪、谁调谁、改动落在哪个文件」；
不回答「要做什么」（`docs/PRD.md` 与 `docs/prd/`）、也不回答「必须怎么做」（`docs/实现约束.md`）。

## 阅读入口

- **何时读**：要定位代码、改代码、判断改动落在哪个文件时，**先读本文件**再看源码。
- **怎么读**：先用 §1 把任务换成「文件 + 符号」；定位不到具体文件时看 §3 目录索引；跟链路走 §4 之后进 `04`；动手前必读 `05` 与 `docs/实现约束.md`。
- **前置约束**：`AGENTS.md`（协作规则）。
- **不适用**：只回答问题、只读排查，可按需直接读源码，不必通读本套。
- **口径优先级**：**代码 > 本套 > 架构 / PRD 行文**。本套与代码不一致 = 本套过期，改代码时同一回合修正本套。

## 2. 分层与依赖方向

依赖方向**只能自上而下**，反向依赖（下层 import 上层）视为违规。

| # | 层 | 目录 | 只做 | 不许 |
|---|---|---|---|---|
| 1 | 入口 / 主题 | `MainActivity.kt`、`ShounaApplication.kt`、`ui/theme/` | 建 NavController、边到边、锁浅色与字号、套主题 | 写业务逻辑 |
| 2 | 页面 | `ui/screen/<页>/` | `XxxRoute`（有状态，唯一职责 `hiltViewModel()` 后下传）＋ `XxxScreen`（无状态，只渲染 UiState + 下发 `onXxx`）＋ `XxxViewModel`（`StateFlow<UiState>` + 编排仓库） | Screen 取 ViewModel / 读 `LocalNavController` / 持有 `TimeUtil`、`ConfigRepository`；ViewModel 持有 Context |
| 3 | 复用 UI | `ui/component/` | 无状态渲染；剪贴板这类**平台 UI 能力**留在组件层 | 写业务判断 |
| 4 | 导航 | `ui/navigation/` | 路由键声明 + 唯一 `NavHost` + 导航动作扩展 + **唯一容器级**系统栏避让 | 取 ViewModel / 写业务逻辑 |
| 5 | 仓库 | `data/repository/` | 用例编排、派生字段（归一化名 / 拼音 / 路径）、失效过滤、事务装配 | 把持久化细节（Entity / DAO）泄漏给上层 |
| 6 | 持久化 | `data/local/` | `Room` 是**唯一可变状态 owner** | 含业务判断 |
| 7 | 常量兜底 | `data/memory/BuiltInData.kt` | 哨兵 + 内置分类 + 首启默认树（只读常量） | 承担可变状态 |
| 8 | 领域 | `domain/` | 纯 Kotlin 模型 + 纯函数（检索判定与打分） | 依赖 Android 框架 |
| — | 工具 | `util/` | 归一化 / 拼音 / 时间 / 路径 / id，纯函数或 `@Singleton` 无状态 | 依赖上层 |

**改动落在哪一层的判据**：口径与展示文案 → 层 2 的 ViewModel；跨表编排与派生 → 层 5；字段与约束 → 层 6；可被多处复用的纯计算 → 层 8 / `util/`。
