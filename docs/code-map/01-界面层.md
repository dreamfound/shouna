# 界面层 · 文件清单

## 文档职责

本文由 [`00-索引.md`](00-索引.md) 分出，记录**界面层的文件清单**：入口与主题 / 导航 / 5 个页面（Route + Screen + ViewModel 成组）/ 复用组件，
每项给「职责 + 关键符号」——定位时直接搜符号名，比按行号跳更抗漂移。
分层与依赖方向、任务定位索引、目录索引见 `00-索引.md`；数据、检索、构建不在此。

## 阅读入口

- **何时读**：任务定位索引指向本文件，或需要确认某个 UI 文件的职责与关键符号时。
- **前置约束**：[`../实现约束.md`](../实现约束.md) §1、§3（动 UI 前必读）；[`../../AGENTS.md`](../../AGENTS.md)。
- **不适用**：只需知道「某功能在哪个文件」时，`00-索引.md` §1 已能回答，不必读本文件。

## 1. 入口与主题

| 文件 | 职责 | 关键符号 |
|---|---|---|
| `MainActivity.kt` | 唯一 Activity：建 NavController 并下发、边到边、**窗口层锁浅色** | `attachBaseContext`（`uiMode = NIGHT_NO`）、`onCreate`（`enableEdgeToEdge()` + `LocalNavController provides rememberNavController()`） |
| `ShounaApplication.kt` | Hilt 入口（空实现，Manifest `android:name` 指向它） | `@HiltAndroidApp` |
| `ui/theme/Theme.kt` | 永久浅色（动态取色锁 `dynamicLightColorScheme`）＋ 字号锁 `fontScale = 1f` | `ShounaTheme`、`LightColorScheme` |
| `ui/theme/Color.kt` / `Type.kt` | 静态配色、排版 | `Purple40` / `PurpleGrey40` / `Pink40`、`ShounaTypography` |

> 浅色与字号是**三层锁**：Compose 侧 `Theme.kt`、窗口侧 `MainActivity.attachBaseContext`、资源侧无 `res/values-night/`。改一处必须核另两处（见 [`05-改动须知.md`](05-改动须知.md)）。

## 2. 导航

| 文件 | 职责 | 关键符号 |
|---|---|---|
| `ui/navigation/ShounaRoute.kt` | 5 个 `@Serializable` 路由键（纯声明，不含 Composable） | `Home`、`QuickAdd`、`Search(initialQuery)`、`ItemDetail(itemId)`、`LocationBrowse(locationId)` |
| `ui/navigation/RouteHandler.kt` | 唯一 `NavHost`（`startDestination = Home`）+ 5 个页面注册 + `LocalNavController` + 容器级系统栏避让 + 6 个导航动作 | `LocalNavController`、`RouteHandler`、`goHome` / `goQuickAdd` / `goSearch` / `goItemDetail` / `goLocationBrowse` / `popBack` |

**接线规则**（改页面先看这条）：`NavController` 只在 `MainActivity` 创建一次 → 经 `LocalNavController` 下发 → **只有 `XxxRoute` 读它**，用来把 `onXxx` 接到 `goXxx` / `popBack`；`XxxScreen` 一律不读。

## 3. 页面（Route / Screen / ViewModel 成组，5 组）

| 目录 | 文件 | 职责 | 关键符号 |
|---|---|---|---|
| `home/` | `HomeScreen.kt` | 搜索框（只读，点击进搜索页）+「＋ 记一件」+「更多」折叠区（内含位置浏览入口） | `HomeRoute`、`HomeScreen`（3 个 `onXxx`） |
| | `HomeViewModel.kt` | 只算首页空态 | `HomeUiState.isEmpty` |
| `add/` | `QuickAddScreen.kt` | 位置条 + 名称（自动聚焦）+ 分类 chips + 折叠备注 + 保存并继续 + 计数器；未选位置时按钮禁用并给原因 | `QuickAddRoute`、`QuickAddScreen`（9 个 `onXxx`） |
| | `QuickAddViewModel.kt` | 录入状态机；**位置必填口径真源**；预选最近位置；保存后保留位置 | `QuickAddUiState`（`canSave` / `selectedLocationId` / `sessionCount`）、`onSaveAndContinue`、`recomputeCanSave` |
| `search/` | `SearchScreen.kt` | 输入即搜；空态展示最近搜索词；结果行 = 名称 + 高亮 + 副标题 + ⚠ | `SearchRoute`、`SearchScreen`（3 个 `onXxx`） |
| | `SearchViewModel.kt` | 去抖检索流 + 索引懒构建／指纹复用 + 最近搜索词写入 + 结果行文案组装 | `SearchUiState`、`SearchResultUi`、`resolveIndex`、`recordIfUseful` |
| `itemdetail/` | `ItemDetailScreen.kt` | 名称 + 面包屑 + 两行时间 + ⚠ + 动作区（按状态切换按钮） | `ItemDetailRoute`、`ItemDetailScreen`（3 个 `onXxx`） |
| | `ItemDetailViewModel.kt` | 详情读取与三个动作的动作壳（`isBusy` 串行化、写失败不弹窗） | `ItemDetailUiState`、`onConfirmStillHere`、`onMarkGone`、`onRestore`、`mutate` |
| `location/` | `LocationBrowseScreen.kt` | 一页一层：面包屑 + 子位置 + 该层物品 + 底部增删改（含删除两档对话框） | `LocationBrowseRoute`、`LocationBrowseScreen` |
| | `LocationBrowseViewModel.kt` | 当前层下钻状态机；树 / 物品 / 阈值的组合；物品行文案 | `LocationBrowseUiState`、`LocationItemUi`、`ROOT_PATH_TEXT`、`load`、`onDeleteCurrent` |

**UiState 归属**：凡是「文案、时间短语、超期判定、路径文本」都在 ViewModel 组装成字符串/布尔后下传；Screen 只渲染。新增展示字段时照此办理。

## 4. 复用组件（`ui/component/`，全部无状态）

| 文件 | 职责 |
|---|---|
| `ShounaSearchBar.kt` | 首页只读形态 / 搜索页可编辑形态共用 |
| `ItemRow.kt` | 物品行：名称 + 高亮 + 可选副标题 + 可选 ⚠ + 可选「长按复制路径」 |
| `CategoryChips.kt` | 分类 chips，再次点击取消选中 |
| `RecentQueryChips.kt` | 最近搜索词（仅搜索页空态；为空整块不渲染） |
| `RelativeTimeText.kt` / `OverdueMark.kt` | 相对时间行 / 超期 ⚠ 标记（判定都由 VM 下传） |
| `LocationBreadcrumb.kt` / `LocationTreeItem.kt` | 面包屑（长按复制）/ 位置树一行（展开态由调用方持有） |
| `LocationPickerSheet.kt` | 录入页位置选择弹层：内嵌整棵树 +「＋ 新建位置」+ 最近使用 |
| `EmptyState.kt` | 首页无物品 / 搜索无结果 |

**复用边界**：组件只接渲染参数与回调；剪贴板（`LocalClipboardManager`）属平台 UI 能力，允许留在组件层，但**判定类逻辑**（是否超期、路径文本）必须由 VM 传入。
