# 界面层 · 文件清单

## 文档职责

本文由 [`00-索引.md`](00-索引.md) 分出，记录**界面层的文件清单**：入口与主题 / 导航 / **11 个页面**（`ui/screen/` 的 Route + Screen 与 `ui/vm/` 的 ViewModel 成组）/ 复用组件（`ui/component/` 5 子包），
每项给「职责 + 关键符号」——定位时直接搜符号名，比按行号跳更抗漂移。
分层与依赖方向、任务定位索引、目录索引见 `00-索引.md`；数据、检索、构建不在此。

## 阅读入口

- **何时读**：任务定位索引指向本文件，或需要确认某个 UI 文件的职责与关键符号时。
- **前置约束**：[`../实现约束.md`](../实现约束.md) §1、§3（动 UI 前必读）；[`../../AGENTS.md`](../../AGENTS.md)。
- **不适用**：只需知道「某功能在哪个文件」时，`00-索引.md` §1 已能回答，不必读本文件。

**状态归属**：上表多数是**纯渲染**；弹层与输入类三件（`LocationPickerSheet` / `VoiceInputDialog` / `PhotoInputRow`）**自带局部 UI 态**（开合、识别阶段、待提交文件名）—— 它们是「系统能力的适配层」，允许持有瞬时态，共同底线是**都不碰数据库**，产物一律经回调交调用方。
