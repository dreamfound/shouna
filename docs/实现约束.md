# 实现约束

> 路径基准：工程根 `shouna/` ｜ 版本 **v1.0**（2026-09-29 立）

## 文档职责

本文件是**横切实现约束的唯一入口**：写代码时必须守什么。

它不回答「代码在哪」（那是 `docs/code-map/`），也不回答「要做什么」（那是 `docs/PRD.md` 与 `docs/prd/`）。
每条约束只写**规则 + 真源位置**，不复制真源的正文；数值、需求条目、字段语义以真源为准。

## 阅读入口

- **何时读**：动 UI / 主题 / 资源 / 数据边界 / 分层归属 / 新增依赖之前必读；定表结构与字段、改检索口径时读 §2、§3。
- **读法**：先看 §1 与 §2（最容易踩），再按改动类型跳到对应节；需要定位具体文件时转 `docs/code-map/00-索引.md` 的任务定位索引。
- **前置约束**：`AGENTS.md`（协作规则）。
- **不适用**：只回答问题、只读排查、只跑构建或测试 —— 这些任务不必读本文件。
- **口径优先级**：**代码 > `docs/code-map/` > 本文件 > `docs/ARCHITECTURE*.md` 与 PRD 行文**。本文件与代码不一致 = 本文件过期，改代码时同一回合修正本文件。

## 2. 状态与数据边界

| # | 约束 | 真源 |
|---|---|---|
| 2-1 | **Room 是唯一可变状态 owner**；内存层只剩只读内置常量 | `data/local/`、`data/memory/BuiltInData.kt` |
| 2-2 | 展示类派生（文案、相对时间短语、超期判定、路径文本、计数）**在 ViewModel 组装成字符串/布尔后下传**，Screen 只渲染 | 各页 `XxxViewModel` |
| 2-3 | 物品名拼音**写入时派生并落列**；位置路径与路径拼音**构建时派生、不落库** | `data/repository/ItemRepositoryImpl.kt`；边界见 `prd/08` 的「检索字段的业务要求」（A-2） |
| 2-4 | 两个时间戳各有唯一写入口，矩阵记在类注释；不要在别处补写 | `util/TimeUtil.kt` 类注释 |
| 2-5 | **跨表写必须走 `TransactionRunner`**；单表写不用事务 | `data/local/TransactionRunner.kt`、`LocationRepositoryImpl` |
| 2-6 | DAO 读写约定：读路径一律 `Flow`、写路径一律 `suspend`；单表更新**不「先查再写」**，靠返回受影响行数判定 | `data/local/dao/*` |
| 2-7 | 仓库接口只暴露领域模型与 `Flow`，**不返回 `*Entity`、不泄漏 DAO**；`internal` 转换函数留在 `Impl` 同文件（供单测直调） | `data/repository/*.kt` |
| 2-8 | `domain/` **不依赖任何 Android 框架类** —— 检索与路径逻辑因此可在 JVM 单测直跑 | `domain/**` |
| 2-9 | 内置哨兵「未指定位置」**对外不外露**：不进选择器、不进浏览页、不可删，只作删位置档 2 的收容位 | `data/memory/BuiltInData.kt`；`LocationRepositoryImpl` 的 `filterNot { it.isBuiltIn }` |

## 3. 分层与归属

| # | 约束 |
|---|---|
| 3-1 | 依赖方向**只能自上而下**（入口/主题 → 页面 → 复用 UI → 导航 → 仓库 → 持久化），下层 import 上层视为违规。分层表见 `docs/code-map/00-索引.md` §2 |
| 3-2 | `NavController` 只在 `MainActivity` 创建一次并经 `LocalNavController` 下发；**只有 `XxxRoute` 读它**，`XxxScreen` 一律不读 |
| 3-3 | `XxxRoute` 唯一职责是 `hiltViewModel()` 后下传；`XxxScreen` 无状态，只渲染 UiState + 下发 `onXxx`；ViewModel 不持有 `Context` |
| 3-4 | 组件（`ui/component/`）只接渲染参数与回调；**判定类逻辑必须由 ViewModel 传入**。剪贴板这类平台 UI 能力允许留在组件层 |
| 3-5 | 新建文件前先按 `docs/code-map/00-索引.md` §1 找既有落点；确认没有合适实现再新建，不做重复实现 |
| 3-6 | 跨页复用的组件放 `ui/component/`，页面私有组件留在 `ui/screen/<页>/` |

## 6. 性能与规模底线

需求侧真源是 `prd/10` §9，**本页不复制数值表**。落地时需自核的量化项：

- 冷启动 ≤ 1.5s、热启动 ≤ 0.5s（NFR-03 / NFR-04）
- 检索 1000 件 ≤ 300ms、5000 件 ≤ 800ms（NFR-05 / NFR-06）
- 位置树 500 节点展开滚动不卡、物品列表 ≥ 1000 条流畅（NFR-07）
- 连续录入 30 件不出现焦点丢失或数据丢失（NFR-08）

检索侧已有微基准单测兜底：`app/src/test/…/domain/search/SearchPerformanceTest.kt`。
