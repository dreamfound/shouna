## 8. 归纳汇总（能力③的具体产出）

### 8.1 「归纳」到底要回答什么问题

| 用户问题 | 对应产出 |
|---|---|
| 我家一共有多少东西？分几类？ | 总览 + 分类分布 |
| 哪些位置塞得最满？ | 位置件数 Top N |
| 哪些记录可能已经不准了？ | 长期未查看 / 超期未确认 |
| 有哪些东西还不该算「有」？ | 已失效物品统计（已丢弃/送人/用掉） |
| 有哪些东西还没归位？ | 待归位清单 |
| 哪些记录信息不全？ | 待补详情清单 |

### 8.2 统计卡片定义（≥4 个）

| 卡片 | 名称 | 数据来源 | 计算口径 | 展示形式 | 点击行为 |
|---|---|---|---|---|---|
| C-1 | **总览** | 物品、位置、存放关系 | 物品总数 = 状态为「在存放中/待归位」的物品数；位置总数 = 全部非内置位置数；存放关系数 = 全部 Placement 条数；**待补详情数 = 按 [08-数据字段业务语义.md](08-数据字段业务语义.md) 的唯一口径判定的物品数** | 4 个数字块 | 点击任一块 → 对应明细列表 |
| C-2 | **分类分布** | 物品 × 分类 | 按分类统计「在存放中/待归位」物品件数；未分类单列 | 横向条形图 + 列表 | 点击某分类 → 该分类物品列表（可按位置再分组） |
| C-3 | **位置件数 Top N（含递归）** | 位置 × 存放关系 | 对每个位置统计其**自身 + 全部子孙**位置下的物品件数（递归口径需在卡片上标注「含子层」） | 排行列表（Top 5，可展开全部） | 点击某位置 → 该位置详情页 |
| C-4 | **超期未确认物品** | 物品.最后确认时间 | 最后确认时间为空 或 距今 > 阈值（默认 6 个月，可配 3/6/12）的物品 | 清单 + 条数徽标 | 点击 → 明细列表，支持逐条「确认还在」与「按位置批量确认」 |
| C-5 | **待归位清单** | 物品.状态 = 待归位 **或** 物品位于「临时位置」 | 两部分去重合计 | 清单 + 条数徽标 | 点击 → 明细列表，支持逐条「归位到…」 |
| C-6 | **已失效物品** | 物品.状态 ∈ {已丢弃, 已送人, 已用掉} | 按状态分组计数 | 分组清单 | 点击 → 明细列表，支持批量恢复、批量彻底删除（二次确认） |
| C-7 | **待补详情** | 物品（**按 [08-数据字段业务语义.md](08-数据字段业务语义.md) 的唯一口径**） | 未填分类 **或** 主位置为内置「未指定位置」的物品（别名/标签/备注/数量为空**不算**） | 清单 + 条数徽标 | 点击 → 批量补录流程（FR-13） |

> 本期落地顺序建议：**C-1（P0）→ C-4、C-3、C-2、C-5、C-7（P1）→ C-6（P1）**。
