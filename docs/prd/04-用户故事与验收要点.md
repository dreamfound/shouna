## 3. 用户故事与验收要点

| 编号 | 用户故事 | 验收要点（Given / When / Then） |
|---|---|---|
| US-01 | As a 收纳者，I want 只填一个名称就能保存物品，so that 我不用被打断 | **Given** 我在「快速录入」页且已选好当前位置<br>**When** 我输入「电风扇」后点保存<br>**Then** 立即生成一条物品记录并归入该位置，不强制填写分类/标签/备注，界面清空并保持焦点在同一输入框可继续录入下一件 |
| US-02 | As a 收纳者，I want 连续录入多件物品而不用每次重选位置，so that 一次收纳不被打断 | **Given** 我已选好位置「纸箱-07」<br>**When** 我连续输入 5 个名称并逐条保存<br>**Then** 5 条都归入「纸箱-07」，且过程中不出现任何位置选择弹窗 |
| US-03 | As a 找东西的人，I want 搜索时用「我平时怎么叫它」就能命中，so that 不用记我当初怎么填的 | **Given** 我录入了「电风扇」<br>**When** 我搜「dsf」/「dianfengshan」/「风扇」<br>**Then** 都能命中该物品（拼音首字母、拼音全拼、名称子串均生效） |
| US-04 | As a 找东西的人，I want 一眼看到完整位置路径，so that 我能直接走过去拿 | **Given** 结果列表命中一条物品<br>**When** 我查看该条目<br>**Then** 显示完整面包屑「储物间 › 货架A › 纸箱-07」，并显示「最后确认时间」，长按可复制路径文本 |
| US-05 | As a 记录者，I want 判断一条记录还准不准，so that 我不被过期信息误导 | **Given** 某物品最后确认时间为 8 个月前<br>**When** 我打开物品详情<br>**Then** 明显提示「已有 8 个月未确认」，并提供「确认还在」按钮 |
| US-06 | As a 记录者，I want 表达「东西没了」而不是只能删记录，so that 保留历史并避免以后误搜到 | **Given** 一件物品实际已丢弃<br>**When** 我把它标记为「已丢弃」<br>**Then** 该物品默认不出现在常规搜索结果中，但在统计页可见并可恢复 |
| US-07 | As a 整理者，I want 把物品从 A 位置移到 B 位置，so that 记录跟上现实 | **Given** 我在物品详情页<br>**When** 我选择「移动位置」并选新位置<br>**Then** 归属更新，`最后变动时间` 刷新为当前时间，旧位置不再显示该物品 |
| US-08 | As a 整理者，I want 一次性看到家里东西都怎么分布的，so that 我知道哪里该清理 | **Given** 我已录入 ≥10 件物品<br>**When** 我打开「归纳统计」<br>**Then** 至少展示 4 个统计卡片（总览、分类分布、位置件数、超期未确认），且每张卡片可点击下钻到明细列表 |
| US-09 | As a 用户，I want 知道我该记什么、不该记什么，so that 这事不会变成负担 | **Given** 我是首次使用者<br>**When** 我第一次进入录入或统计页<br>**Then** 能看到一段简短的「建议记录什么」引导（不超过 5 条），且可关闭不再显示 |
| US-10 | As a 用户，I want 数据只在我手机里，so that 我不用担心隐私 | **Given** 应用已安装<br>**When** 我查看权限与设置页<br>**Then** 应用不申请网络权限，设置页明确说明「所有数据仅存本机」，并提供导出备份入口 |
