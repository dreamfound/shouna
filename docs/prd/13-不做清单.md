## 附：本期明确「不做」清单（防止范围蔓延）

| 不做项 | 原因 |
|---|---|
| 拍照 / 扫码 / 语音录入 | 提升录入体验但显著增加实现与权限成本，下一期候选 |
| 借出 / 归还 / 保质期提醒 | 用户未圈选，本期不做任何 UI |
| 云同步 / 账号 / 多设备 / 家庭协作 | 用户已拍板「仅本机离线」 |
| 系统通知与提醒 | 为避免额外权限，本期以统计页替代 |
| 回收站（软删除） | 用「状态 + 二次确认」替代，下一期评估 |
| 记录变更历史（位置轨迹） | 本期仅保留「最后变动时间」单值 |
| 导出可读报表 | 本期只做完整数据备份导出 |
| CSV 导出格式（便于人看） | 本期只做 JSON（完整可回导），CSV 顺延下一期（见 [11-待确认问题清单.md](11-待确认问题清单.md) 的 Q5） |
| 系统自动备份（Auto Backup） | 详见 [10-非功能需求.md](10-非功能需求.md) 的「系统自动备份与『仅存本机』的承诺冲突」：推荐关闭（选项 A），待用户拍板；**不是「不做备份」，而是把备份的选择权交还给用户（手动导出）** |
