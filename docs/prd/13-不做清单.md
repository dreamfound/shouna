## 附：本期明确「不做」清单（防止范围蔓延）

| 不做项 | 原因 |
|---|---|
| 拍照 / 扫码录入 | 提升录入体验但显著增加实现与权限成本，下一期候选 |
| **语音录入** | **由「下一期候选」改列为「V2 规划项」**：V2 要做的不是「语音代替打字」，而是「**语音 → 文本 → AI 结构化 → 人工确认**」的完整链路（见 [14-分期与V2-AI规划.md](14-分期与V2-AI规划.md) 的 `V2-FR-01`～`V2-FR-04`）。**V1 仍明确不做**：不做录音、不申请麦克风权限、不占任何 UI；对应 **FR-18 保持 P2 顺延、该行不动** |
| 借出 / 归还 / 保质期提醒 | 用户未圈选，本期不做任何 UI |
| 云同步 / 账号 / 多设备 / 家庭协作 | 用户已拍板「仅本机离线」 |
| 系统通知与提醒 | 为避免额外权限，本期以统计页替代 |
| 回收站（软删除） | 用「状态 + 二次确认」替代，下一期评估 |
| 记录变更历史（位置轨迹） | 本期仅保留「最后变动时间」单值 |
| 系统自动备份（Auto Backup） | **已定案：不做（U-1，用户 2026-09-24 拍板选项 A）**，详见 [10-非功能需求.md](10-非功能需求.md) §9.1。落地为 `android:allowBackup="false"`（或显式排除数据库）。**2026-09-29 更新**：手动导出 / 导入（FR-42 / FR-43）亦已由用户**永久废弃**，因此**本机之外不存在任何备份或迁移通道**；数据可靠性只由 **FR-41 本地持久化（Room 本地存储）**承担（见 [05-需求池.md](05-需求池.md) §4.11） |
| **两个独立 APK（`shouna-lite` / `shouna-full`）** | 本项目已定「仅本机离线、无账号、无云同步」，两个 APK 的数据目录**物理隔离、无法共享**；在 `allowBackup=false` 下**卸载 A 装 B = 数据全丢**，且**不存在任何互通手段**（手动导出 / 导入已于 2026-09-29 永久废弃，见 [05-需求池.md](05-需求池.md) §4.11）——与「降低学习成本」的诉求正面冲突。改用**单 App + 分层暴露**（见 [05-需求池.md](05-需求池.md)、[07-页面结构与关键交互.md](07-页面结构与关键交互.md)）。此项待用户确认，见 [12-待用户确认清单.md](12-待用户确认清单.md) 的 **U-8** |
| **首次启动的档位 / 模板选择弹窗** | 分层后 F1 自解释，**首启不设任何选择**（不选档位、不选位置模板），默认位置树直接预置（见 [12-待用户确认清单.md](12-待用户确认清单.md) 的 U-4） |
| **分类分布 / 位置件数 TopN / 已失效物品 三张统计卡片** | 顺延下一期（详见 [09-归纳汇总.md](09-归纳汇总.md) §8.2.2） |
| **首次使用引导页** | 对应 **FR-46 删除**：分层后 F1 自解释，独立引导页属纯学习成本 |
| **V2 的 AI 能力（语音识别 / 文本送 AI / AI 格式化 / 自然语言搜索）** | **不属于本期**：V1 **只留「缝」不实现**——不写任何 AI 逻辑、不申请任何新权限、不出现任何 AI 入口与文案。预留位定义见 [14-分期与V2-AI规划.md](14-分期与V2-AI规划.md) 的 `V2-SEAM-01`～`V2-SEAM-06` |
| **暗色模式 / 深色适配 / 字号跟随系统** | **产品永久移除（2026-09-28）**，**不是**「本期顺延」——对应 **FR-48 删除**，并连带删除 **NFR-16**（深色跟随）与 **NFR-13**（字号缩放）。代码侧**强制浅色**并锁定 `fontScale = 1f`（见 [shouna/docs/ARCHITECTURE.md](../ARCHITECTURE.md) v2.2 §5.1）；**不进 F2、不预留** |
