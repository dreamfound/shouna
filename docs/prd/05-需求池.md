## 4. 需求池

> 优先级定义：**P0 = 本期必须做（支撑「记录-查找」闭环的最小集合）**；**P1 = 本期应做（显著提升留存与可用性）**；**P2 = 本期可不做（明确标注是否本期做）**。

### 4.1 位置与层级（核心能力①）

| 编号 | 需求名 | 描述 | 优先级 | 是否本期做 | 验收要点 |
|---|---|---|---|---|---|
| FR-01 | 多级位置树 | 支持「房间 → 柜子 → 箱子 → 格」任意层级嵌套的位置树 | **P0** | 是 | 可新建带父子关系的层；可展示任意节点下的子节点与直属物品 |
| FR-02 | 位置路径面包屑 | 任意物品/位置展示从根到当前的完整路径 | **P0** | 是 | 路径文本可完整展示、可复制 |
| FR-03 | 位置重命名 / 备注 | 位置名称可改、可加备注（如「最底层，靠墙」） | **P0** | 是 | 重命名后，所有关联物品的路径展示同步更新 |
| FR-04 | 位置移动 / 合并 | 可把子位置整棵移到别处；可把两个位置合并 | P1 | 是 | 移动后子孙节点与物品归属保持正确，路径自动更新 |
| FR-05 | 位置删除保护 | 删除非空位置时须二次确认并说明其下物品去向（一并删除 / 迁移到指定位置） | **P0** | 是 | 不会出现「物品挂在已删除位置」的孤儿数据 |
| FR-06 | 临时位置标记 | 位置可标记为「临时/待归位区」，其下物品在统计与列表中高亮 | P1 | 是 | 临时位置的物品在首页有独立入口可查 |
| FR-07 | 位置层级模板 | 首次启动可选预设（如「家：客厅/卧室/厨房/储物间」），也可从空开始 | P2 | 是（轻量） | 选模板后一键生成基础位置树，可自由增删 |
| FR-08 | 位置数量/容量提示 | 位置可记录「容量描述」与物品件数合计 | P2 | 否（下一期） | — |

### 4.2 录入（决定生死的能力）

| 编号 | 需求名 | 描述 | 优先级 | 是否本期做 | 验收要点 |
|---|---|---|---|---|---|
| FR-09 | 极简录入（仅名称必填） | 录入表单默认只有「物品名称」一个必填项 | **P0** | 是 | 只填名称即可保存成功，其余字段均为可选/可后补 |
| FR-10 | 连续录入模式 | 选定位置后，可连续录入多条，逐条自动归入该位置 | **P0** | 是 | **连续录入 5 件 ≤ 40 秒**；保存后自动清空并聚焦输入框，显示「已连续录入 N 件」 |
| FR-11 | 最近使用位置快捷入口 | 录入页顶部展示最近使用的 3–5 个位置一键选中 | **P0** | 是 | 二次录入无需重新遍历位置树，1 次点击即定位 |
| FR-12 | 可选快速分类 | 提供少量内置分类 chips（电器/衣物/工具/文具/药品/其他…），可一键点选也可跳过 | P1 | 是 | 点击 chip 即赋值，不选不影响保存 |
| FR-13 | 草稿箱 / 待补详情 | 只填了名称的记录归为「待补详情」，统计页可集中补录（**判定口径唯一，见 [08-数据字段业务语义.md](08-数据字段业务语义.md) 的「待补详情」判定口径**） | P1 | 是 | 列表中可区分「信息完整」与「待补详情」，支持批量进入补录 |
| FR-14 | 录入时重名提醒 | 保存时若存在同名/高度相似物品，提示「家里可能已有这件」 | P1 | 是 | 提示为非阻塞（可继续保存），并提供跳转查看已有记录 |
| FR-15 | 同一位置批量连续录入后的批量编辑 | 连续录入的多条可批量选分类/加标签 | P1 | 是 | 可多选后一次赋值 |
| FR-16 | 拍照记录物品 | 给物品拍照作为辨识 | P2 | **否**（下一期） | 本期仅在数据模型中预留字段位 |
| FR-17 | 扫码录入 | 扫条码自动带出名称 | P2 | **否**（下一期） | — |
| FR-18 | 语音输入 | 用语音代替打字 | P2 | **否**（下一期） | — |

### 4.3 查找与查询（核心能力②）

| 编号 | 需求名 | 描述 | 优先级 | 是否本期做 | 验收要点 |
|---|---|---|---|---|---|
| FR-19 | 全局搜索 | 单一搜索框，跨名称/别名/分类/位置/标签检索 | **P0** | 是 | 1000 件物品时响应 ≤ 300ms；输入即出结果（无需点搜索按钮） |
| FR-20 | 拼音首字母与全拼检索 | 「dsf」→ 电风扇；「dianfengshan」→ 电风扇 | **P0** | 是 | 离线内置拼音支持，无需网络 |
| FR-21 | 按位置浏览（下钻） | 从位置树逐层进入，查看该位置直属及递归物品 | **P0** | 是 | 面包屑可回退；展示「本层 N 件 / 含子层共 M 件」 |
| FR-22 | 搜索筛选 | 结果可按「分类 / 位置 / 状态 / 是否有待补详情」筛选 | P1 | 是 | 筛选条件可叠加、可一键清空 |

| FR-24 | 仅看可信记录 | 可切换「只显示近期确认过的记录」 | P2 | 否（下一期） | — |
