## 11. 待用户确认清单（需用户拍板）

> 每条的最后一列 = **若用户不回复，工程将按此默认值推进**，以保证不阻塞交付。

**关于 U-1 的处置（已定案）**：用户已拍板**选项 A —— 不做系统自动备份**。这条之所以曾被列为本清单中「最需要明确表态」的一条，是因为它是唯一**无法事后低代价反悔**的决策（一旦按 B 运行过，云端可能已留下副本）。现既定为 A：数据 100% 只在本机、卸载即永久丢失，「仅存本机」的承诺在系统层面成立；其代价（换机 / 误卸载 / 设备损坏 = 数据全丢）由用户自行规避，**唯一兜底是手动导出 JSON（FR-42），因此该入口必须显眼**。
> 其余各项（U-3 / U-5 / U-6 / U-7 / U-8）均为**可配置项**，用户随时能在设置页改，属低反悔成本，继续按推荐值推进。
